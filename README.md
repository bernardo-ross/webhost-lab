# WebHost Lab — Infraestrutura e Hospedagem Web

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com foco na implementação de um ambiente de hospedagem web utilizando virtualização, Windows Server, IIS e MySQL.

## Sobre o projeto

O WebHost Lab teve como objetivo configurar um servidor virtual capaz de hospedar um site e disponibilizá-lo para acesso por outra máquina na rede.

O projeto também envolveu a implementação de um banco de dados para armazenamento e consulta de informações.

## Tecnologias utilizadas

- Windows Server 2022
- Oracle VirtualBox
- IIS (Internet Information Services)
- MySQL 8.4
- HTML5
- CSS3
- SQL

## Implementações realizadas

- Criação e configuração de máquina virtual.
- Configuração do Windows Server.
- Configuração de endereço IP e rede.
- Instalação e configuração do IIS.
- Hospedagem de site desenvolvido em HTML e CSS.
- Instalação e configuração do MySQL.
- Criação de banco de dados e consultas SQL.
- Configuração de permissões e firewall.
- Testes de conectividade e acesso externo ao site.
